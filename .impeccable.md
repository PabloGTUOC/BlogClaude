# enderthoughts — Design Context

## Product
Private family photo blog. Two zones: analog (35mm film rolls) and digital. The public home feed shows approved photos from both zones; the analog section is a dedicated gallery browser for film rolls; the digital section is similar. Admin area for managing uploads, rolls, publishing.

## Audience
Primary: the owner (Ender). Secondary: approved family members. Access is gated — unauthenticated visitors see only the public feed.

## Aesthetic Direction
**Retro-brutalist CRT terminal from an alternate 1984** — the tagline: "a transmission from a slightly alternate 1984 where the network was wired a decade early and photography went digital while still feeling chemical." The interface should feel like a slightly too-capable operating system running on a phosphor-green CRT monitor. Not ironic nostalgia — sincere and inhabitable. The brutalism comes from raw construction: uppercase labels, bracket notation for buttons, 1px grid lines instead of drop shadows, no rounded corners anywhere.

## Brand Personality (3 words)
Chemical. Mechanical. Clandestine.

## Theme
Dark only. Photography is the primary content and must read on black.

## Typography Stack (current)
- Display: VT323 — phosphor-green headings, large scale
- Label: Share Tech Mono — small uppercase UI labels
- Body: IBM Plex Mono — body text (⚠ on reject list, flagged for replacement)
- UI: Orbitron — status bar, clock, zone indicators

## Color Palette (hex, dark)
- void #0A0A0F, surface #111118, panel #1A1A26, grid #1F1F2E
- phosphor #00FF94 (primary accent, green glow)
- amber #FFB347 (secondary, captions, warm content)
- neon-red #FF2D55 (danger, selection, chromatic aberration effect)
- dust #4A4A6A, fog #8A8AAA, chrome #C8C8E8, white #F0F0FF

## Signature Details
- `[ BRACKET ]` notation for all buttons and interactive labels
- Blinking cursor (`_`) at end of loading states and body copy
- CRT boot flash on page load (scaleY 0.004 → 1, opacity 0 → 0 via crt-on keyframes)
- Scanlines on body (`repeating-linear-gradient` pseudo-element)
- SVG grain overlay in Home.vue
- Horizontal terminal wipe page transitions
- Status bar fixed at bottom: live clock, zone dot indicator, user info
- `// COMMENT STYLE //` for empty states and section markers

## Tech Stack
Vue 3 (Options API + setup()), Pinia, Express.js, MySQL 8.0, Tailwind CSS + custom CSS vars, Vite
